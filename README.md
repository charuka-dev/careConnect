# CareConnect – Elderly Care Mobile Application

**CareConnect** is an Android mobile application designed to simplify elderly care management and improve coordination between caregivers and family members.

The application provides a platform for managing elderly profiles, organizing caregiver tasks, and sharing real-time care updates to support better communication and more efficient elderly care.

## ✨ Features

- **Elderly Profile Management** – Manage elderly individuals' profiles and related information.
- **Caregiver Task Management** – Organize and manage elderly care-related tasks.
- **Real-Time Care Updates** – Share updates about elderly care activities.
- **Caregiver Coordination** – Improve collaboration between caregivers.
- **Family Communication** – Help family members stay informed about elderly care activities.

## 🛠️ Technologies Used

- **Programming Language:** Kotlin
- **Platform:** Android
- **UI Design:** XML
- **Backend / Database:** Firebase
- **Development Environment:** Android Studio
- **Version Control:** Git & GitHub

## 📱 Application Overview

CareConnect aims to make elderly care management more organized, accessible, and efficient through a mobile-based solution.

## 🚀 Getting Started

### Prerequisites

- Android Studio
- Android SDK
- JDK
- Firebase project configuration

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/charuka-dev/CareConnect.git
   ```

2. Open the project using Android Studio.

3. Configure Firebase by adding your own `google-services.json` file to the appropriate app directory.

4. Sync the Gradle dependencies.

5. Build and run the application on an Android emulator or physical device.
